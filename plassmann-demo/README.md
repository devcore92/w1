# plassmann-demo

Unverbindlicher, mobiloptimierter Website-Entwurf für den Malerbetrieb
**Udo Plaßmann Malermeister** (Gütersloh-Isselhorst).

> **Hinweis:** Dies ist ein unverbindlicher Design-Vorschlag, erstellt von
> Vincent Lokotsch. Es handelt sich **nicht** um die offizielle Website der
> Firma und es besteht keine geschäftliche Verbindung. Die Inhalte dienen
> ausschließlich der Veranschaulichung.

## Live-Vorschau

Nach dem ersten erfolgreichen Workflow-Lauf ist die Seite erreichbar unter:
`https://devcore92.github.io/plassmann-demo/`

## Aufbau

- `index.html` – einseitige Website (Hero, Leistungen, Über uns, Kontakt),
  komplett self-contained (CSS/JS inline), responsive.
- `.github/workflows/pages.yml` – aktiviert GitHub Pages und deployt bei jedem
  Push auf `main`.
